qdgeo examples

Buffer, boolean geometry and spatial predicates running in WebAssembly. Five pages do all four boolean operations and the buffer, with live controls, and one asks the predicates — all against the same module.

The module is one file, 133.5 KB raw and 50.5 KB gzipped, with no host imports.

Plain canvas

No dependencies and no projection. Drag two shapes and watch the result update; includes a ring-with-hole preset.

OpenLayers

The flat layout qdgeo returns, passed in both directions with no conversion either way.

MapLibre GL JS

Geometry in Web Mercator metres, so a buffer distance is metres, with toArrays() for the nested form.

Leaflet

A small, widely used mapping library, with qdgeo/leaflet converting in both directions.

deck.gl

Flat typed arrays to the GPU, with no coordinate read or copied on the way — qdgeo/deck is the conversion.

Predicates

intersects, contains, touches and the rest, with the DE-9IM matrix they come from. Polygons, lines and points, dragged on a canvas.

API reference

Every export of qdgeo, qdgeo/deck and qdgeo/leaflet, generated from the source doc comments.
