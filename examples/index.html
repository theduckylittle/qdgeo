qdgeo examples

Buffer and boolean geometry running in WebAssembly. Each page does all four boolean operations and the buffer, with live controls, against the same module.

The module is one file, 112 KB raw and 43.9 KB gzipped, with no host imports.

Plain canvas

No dependencies at all. Drag two shapes and watch the result update. Includes a ring-with-hole preset.

OpenLayers

Reads getFlatCoordinates() and getEnds() straight across, with no format conversion in between.

MapLibre GL JS

Converts to GeoJSON on the way out, and does the geometry in Web Mercator so buffer distances are in metres.
