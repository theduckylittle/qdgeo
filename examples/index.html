qdgeo examples

Buffer and boolean geometry running in WebAssembly. Each page does all four boolean operations and the buffer, with live controls, against the same module.

The module is one file, 135 KB raw and 50.8 KB gzipped, with no host imports.

Plain canvas

No dependencies and no projection. Drag two shapes and watch the result update; includes a ring-with-hole preset.

OpenLayers

The flat layout qdgeo returns, passed in both directions with no conversion either way.

MapLibre GL JS

Geometry in Web Mercator metres, so a buffer distance is metres, with toArrays() for the nested form.

Leaflet

A small, widely used mapping library, with qdgeo/leaflet converting in both directions.

deck.gl

Flat typed arrays to the GPU, with no coordinate read or copied on the way — qdgeo/deck is the conversion.
